\# VitaPulse AI



AI-Powered Fitness Intelligence Platform built using Spring Boot Microservices, MongoDB, RabbitMQ, and React.



\## Overview



VitaPulse AI tracks user fitness activities, analyzes performance, and generates AI-powered health recommendations using Gemini AI.



\## Microservices



\- API Gateway

\- Eureka Discovery Server

\- Config Server

\- User Service

\- Activity Service

\- AI Service



\## Features



\- User Registration \& Profile Management

\- Activity Tracking

\- Fitness Analytics

\- AI Recommendations

\- Service Discovery

\- Centralized Configuration

\- Event-Driven Communication using RabbitMQ
